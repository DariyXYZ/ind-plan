# IND PLAN — кликабельный MVP генератора планировок

Сайт: https://dariyxyz.github.io/ind-plan/ (GitHub Pages, `index.html`).
Исходник — `ind-plan-mvp.html` (он же артефакт https://claude.ai/artifact/NdT8oJCUDSJch1sD9veZyh); `index.html` собирается из него.

Флоу: вход → мои планировки → рабочее поле (контур → нормы и ТЗ → варианты) → правка → экспорт.

## Редактор плана
Перенесён из прототипа редактора IND PLAN (OpenPencil, ветка `ind-plan/plan-mode`). Открывается на том же поле: карандаш в шапке варианта, любой инструмент нижней панели (W стена, D дверь, O окно, S стояк, R помещение, F мебель) или клик по стене/мебели. Справа вместо «Генераций» — «Свойства»; «Готово» возвращает генерации, правки сохраняются как новая версия варианта (v2, v3…).

- Наружный контур из модели на замке (как Revit-основа); перегородки двигаются, тянутся за концы, меняют тип и толщину.
- Двери (открывание 4 вида, петли, ширина, отступ от угла), окна, проходы; лишний проём в наружной стене можно заложить.
- Мебель из модели — отдельные предметы (сдвиг, поворот, зеркало, удаление) + каталог IND, у стены встаёт спинкой к стене.
- Площади помещений пересчитываются при каждой правке: растр 20 мм, проёмы закрыты, заливка от подписей; пунктир — условные границы открытых зон.
- Ctrl+Z / Ctrl+Shift+Z, Delete, Esc, Ctrl+колесо — масштаб, средняя кнопка — двигать поле.

## Планировки из Rhino (Rhino-Test-Model-2.3dm, кв. 28, 106,21 м²)
1. В Rhino `MCPStart`, затем `sh rhino-export/run_in_rhino.sh rhino-export/1_extract_in_rhino.py` → `rh/plans.json`.
2. `python -X utf8 rhino-export/2_room_areas.py` → `rh/rooms.json` (точки подписей и площади).
3. `python -X utf8 rhino-export/3_build_symbols.py` → `rh/sym.html` + `rh/rh.js` (символы для превью; вставлены в html вместе с `glue.js`).
4. `python -X utf8 rhino-export/4_build_model.py` → `rh/model.js` + `rh/msym.html` — редактируемая модель: стены, проёмы, мебель, подписи. Условные границы — `rh/cuts.json`.
5. `python -X utf8 rhino-export/5_inject_editor.py` — вставляет модель и `editor.js` в `ind-plan-mvp.html` (повторный запуск заменяет вставку).
6. `python -X utf8 rhino-export/6_build_pages.py` → `index.html` для Pages.

## Финальный интерфейс (rhino-export/app.js)
Слой поверх MVP и редактора, вставляется `5_inject_editor.py` после `v4.js`. Всё, кроме самой генерации:
- **Контур с нуля:** W или клик по полю → наружные стены по оси (300 мм), замыкание в первую точку → вход → окна → стояк. Шаги вверху поля, проверка слева, кнопка «Создать» включается, когда есть замкнутый контур, вход и окно.
- **Прямоугольник по размерам**, **пример кв. 28**.
- **Импорт:** Revit `.json` (`ind-plan`, `ind-plan-base` с выбором этажа), AutoCAD `.dxf` (ASCII; внешняя замкнутая полилиния → стены 300 мм внутрь, остальное подложкой), PDF/PNG/JPG подложкой с калибровкой масштаба (линейка, два клика + длина). Перетаскивание файла на поле. Понятные ошибки: DWG, RVT, IFC, HEIC, битый JSON, чужой формат, двоичный DXF, PDF с паролем, больше 25 МБ.
- **Файлы:** сохраняются в localStorage браузера, список «Мои планировки» (переименовать, копия, удалить с «Вернуть»), пример — только просмотр + «Сохранить копию». Имя файла правится по клику.
- **Запуск (заглушка):** очередь → прогресс → готово; «Остановить» (списываются только готовые), резерв токенов, нехватка токенов, пропала сеть. Для своего контура — честное «генератор пока не подключён», токены не списываются.
- **Экспорт:** JSON для Revit (с исходными координатами импорта), SVG, PNG 2×, PDF через печать.
