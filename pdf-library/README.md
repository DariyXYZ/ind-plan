# Библиотека планировок IND из PDF

Пересобрать индекс и отчёт из проверенных результатов одной командой из корня проекта:

```powershell
python -X utf8 pdf-library/rebuild.py
```

Команда берёт листовые JSON из источников в `sources.json`, заново собирает библиотеку в `out_rebuilt`, затем создаёт `pdf-library/db/plans.sqlite`, `db/library.json`, `db/library_engine.json` и `coverage.md`. Старые `out_*` не меняются. Формат описан в `SCHEMA.md`; пример поиска:

В версии 2 комнаты дополнительно представлены полилиниями `rings` и направленными обходами `outline_graph`. Каталог рисует контуры; `rects` сохранены для генератора. Разбор ограничений ContourGraph и схема мебели — в `CONTOUR_GRAPH_REVIEW.md`. Проверка после пересборки: `python -X utf8 pdf-library/validate_outline_graph.py`.

Непромеренные исходные планы хранятся отдельно в `catalog/source_refs.json` и показываются в каталоге с PDF и предпросмотром. Они не входят в `db/library.json` и не используются генератором. Для QUBE Residential Dubai добавлены четыре таких листа: A3, A2, A1, A6. Их PDF не содержит площади и масштабной сетки, поэтому размерную геометрию из них пока нельзя считать проверенной.

```powershell
python -X utf8 pdf-library/query.py --type 2E --w 6000 --d 7000 --must wardrobe -k 5
```

Экспериментальный режим для PDF с перегородками из пар линий (PowerShell): `$env:MODE='lines'; python -X utf8 pdf-library/run.py <новая_папка> <лист.pdf#N>`, где `N` — номер страницы с нуля. Его результаты пока не добавлены в `sources.json`: пилот Touch Dovzhenko на трёх листах не прошёл проверки. Оверлеи лежат в `out_touch_lines_pilot`; `probe_line_pairs.py` строит диагностику пар.

Векторные PDF-листы планировок → квартиры в формате Б (контур, окна, стояки, помещения прямоугольниками, связи) → библиотека референсов для движка.

```
python -X utf8 run.py <папка_вывода> <файлы.pdf ...>   # извлечение + картинки проверки
python -X utf8 analyze.py <папка_вывода>                # признаки, приёмы, дедупликация → _library.json, _report.json
```

Что читает с листа: цветные заливки = помещения (до осей стен), тёмная заливка (0.33) = стены, серые квадраты = стояки, текст «Название / NN.NN м²» = подпись.
Связь = участок общей границы без стены: ≤1 м дверь, больше — проём. Разрыв к свободному пространству: улица в 1.2 м — окно, внутренний коридор — вход.
Проверки: 1 вход, все комнаты достижимы, у спален/КГ есть окно, сумма площадей = итог на листе (±0.06), есть КГ.

## Граф стен (ContourGraph, драфт PLAN AI 2.0)
`python -X utf8 to_contour_graph.py` → `db/contour_graphs.json` (после `rebuild.py`). Ось стены = середина зазора между заливками пола; толщина = зазор; дыры периметра (шахты, колонны) — в `PerimeterHoles` (в драфте такого поля нет). Допущения записаны в `Assumptions` каждой квартиры. Каталог рисует планы по этому графу.
