## Причины отказов v1 (0 из 12) — не граф
1. **Вертикальные подписи** («Гардеробная / 4,60 м²», `dir=(0,-1)`) не читались → недостача ровно на их сумму (1.3.1: 98.21 − 84.67 = 4.82+4.60+4.12).
2. **Итога на листе нет в «м²»** — он в табличках квартир: код `1.3.1`, тип `2KXL`, площадь `98,21`.
3. **Окна** = витражи: тонкие серые заливки 0.753 (~2 ед.) по фасаду, не разрыв стены.

## Правки `extract.py`
- `labels()`: подписи с направлением `h` / `u` (имя левее площади) / `d` (правее); диагональные игнорируются.
- Итоги из табличек квартир (только если на листе нет итогов в м²), допуск `max(0.06, 0.3%)`: таблица считается по неокруглённым площадям (1.7.1: сумма подписей 102.60, в табличке 102.72; ручная сверка). Пропавшая комната (≥2 м²) ловится. В `checks` добавлены `total_src` (sheet|table|rooms) и `total_dev`.
- Витражи → окна соседнего не-мокрого помещения (окрестность 8 ед.).
